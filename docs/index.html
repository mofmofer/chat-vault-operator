Chat Vault Operator

Android版ChromeでChatGPTの複数チャットを選択し、まとめてアーカイブするためのツールです。

  1. 上のボタンでコードをコピーします。
  2. Chromeで任意のページをブックマークし、そのブックマークを編集します。
  3. 名前を「Chat整理」、URLをコピーしたコードへ置き換えます。
  4. chatgpt.comを開き、アドレスバーに「Chat整理」と入力して候補のブックマークを実行します。
  5. 一瞬だけ公開CDNのタブが開き、実装をChatGPTへ渡した後に閉じます。

このツールは削除を行いません。実装コードは公開リポジトリの固定コミットから受け取りますが、アクセストークン、会話タイトル、会話本文を外部へ送信しません。
